# Happy Answers

"What did you notice today that made you smile?" Static site (`public/`) backed by Supabase, hosted on Cloudflare.

- Table + RLS: `supabase/migrations/`
- Public Supabase URL/anon key: `public/config.js`
- Deploy: `npx wrangler deploy`
- Local preview: `npx wrangler dev` (or any static server on `public/`)
